# Fonts

NotoSans.ttf is the unmodified variable Noto Sans font distributed by Google Fonts:
https://github.com/google/fonts/blob/main/ofl/notosans/NotoSans%5Bwdth,wght%5D.ttf

Downloaded 2026-10-31. SIL Open Font License 1.1: see OFL.txt.
The default face supports Vietnamese. Weight/width use the font defaults.
